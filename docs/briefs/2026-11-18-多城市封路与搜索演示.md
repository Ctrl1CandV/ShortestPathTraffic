# 第二轮开工确认单｜多城市路网、封路与搜索演示

日期 2026-11-18

状态 **已确认并通过提交前验收（2026-11-18）**

基线为本地提交 `46cc755`。本轮接续[第一轮课程设计](2026-11-17-城市交通最短路径.md)。

## 一句话目标

老师能在离线网页中加入一座城市，在搜索前亲手改变可通行的道路，再看 Dijkstra 和 A* 怎样从同一起点搜索到终点。

## 项目档位与使用者

交付物是供学生答辩、老师操作的 Windows 本地项目，包含运行说明、随附的城市数据和测试。本轮作为一个完整功能，按课程提交档验收。

一条完整的演示流程是：切换到北京，或现场导入济南 → 选起终点 → 在地图上指定封路或随机封路 → 开始搜索 → 暂停观察算法进展 → 查看路线和代价 → 保持相同条件，换另一种算法对照。老师也可以在全部道路开放时直接搜索。

## 倾向

- 沿用 Python、本地网页、浅色二维地图、中文桌面界面及第一轮的三种权重。地图从项目内的数据绘制，启动和演示均可离线完成。
- 复用现有环境。安装新包、新建 Python 环境或改动项目目录之外的内容前，先征得用户同意。

## 功能与架构

### 城市与路网数据包

- 内置天津五大道—小白楼、北京东城两个样区，随项目另附一份可导入的济南大明湖南侧样区包。每个样区都提供多个有名称的起终点、可运行的演示案例、数据来源、许可和提取日期。用各城市实际可通行的路网核验演示对。
- 切换城市时加载对应的道路、地标和演示案例。天津沿用原有快照和一键演示。北京、济南沿用机动车筛选、单行方向、共享节点连接和教学权重的口径。
- 页面可从本地文件导入符合项目格式的城市包。导入成功即可查询，并可从页面移除已导入的城市。用户导入的副本保存在项目目录内，重启后仍可用。移除只作用于该副本。包格式与示例文件位置写入 README。
- 导入时检验必要元数据、坐标、道路节点与地标引用等。损坏的包、重复城市标识给出明确提示，保留原有城市和当前可用数据。

### 搜索前修改道路

- 「修改道路」可在选终点或运行任何算法之前使用。进入编辑后可在地图点选要封闭的路段，也可随机封路；封闭状态在图上立即可见，页面列出已封路段，支持逐段恢复和全部恢复。
- 操作单位为当前城市数据包中一段可辨认的道路线形。对同名但独立的路段分别标识、分别高亮。封闭后从寻路图中排除该段原有的全部通行方向，恢复时按原有单行或双向规则通行。原始城市包保持可复用。
- 随机按钮从当前城市尚开放的路段中等概率抽取，每次新增 1～3 段，余量不足时以余量为限。抽取与当前路线无关，因此重新搜索可能绕行、不可达，也可能仍走原路线。
- 同一城市的封路状态在当前页面会话内保留，供反复搜索和算法对照。各城市分别记录。变更城市、端点、策略或封路后，结束过期播放并清除失效结果；点击「开始搜索」后按当前条件重新计算。

### 算法与真实搜索动画

- 手写 Dijkstra 和 A*，均支持最短距离、预计最快、优先路面条件。对同一城市、起终点、权重和封路集合，两者求得相同的最优代价，并列最优时允许选择不同路径。
- A* 用到终点的球面直线距离估计剩余代价。时间和路面策略按当前城市的单位距离代价下界换算，保证估计值与目标单位一致且不高估。用 NetworkX 对照开放和封路后的最优值。
- 后端记录每次有效取出节点的实际顺序及对应搜索信息。地图按这份记录播放，显示已经搜索的范围、当前处理的路口和已处理节点数。默认播放能看清搜索推进；可暂停、继续、调速和跳到结果。到达终点或确认不可达时结束播放。
- 搜索结束后高亮最终路线，给出经过道路、路线长度、预计时间和路面加权代价。相同条件下可以对照两个算法实际处理的节点数与最优代价。节点数采用同一统计口径；案例结果随输入和封路状态计算。

## 内容与展示

地图继续占主要区域。侧栏按操作顺序组织城市、起终点、道路修改、权重与算法、开始搜索。播放时在地图附近显示播放控制和进度，结束后显示路线结果与算法对照。页面标明随机封路是模拟情景，并保留数据署名与教学权重说明。

## 审美

沿用现有浅色地图的投影可读性。已搜索范围用较轻的标记，当前节点和最终路线更醒目，封路另用线型或符号区分。1280 × 720 和 1920 × 1080 两档下检查搜索中、暂停和结果画面。页面实现和实屏检查沿用 product-design 与 frontend-craft。

## 拟定的实现选择

- 城市包持久保存，模拟封路随页面会话结束而清空。这样老师能提前准备导入数据，也能在下一次演示时从全开放路网开始。
- 默认用 Dijkstra 开始，通过切换算法在同一张地图上观察 A*。提供逐次播放和同条件的统计对照，避免两组搜索标记相互遮挡。
- 指定封路采用地图点选。每次封闭的实际范围在图上高亮，用户可以在搜索前检查并撤销。
