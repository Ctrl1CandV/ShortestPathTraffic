# 图论及其应用 · 六场景课堂演示

一个离线网页，六个应用，每个只运行一种教材算法。教师可现场指定输入；组员可对着当前图和这次计算的步骤讲解。[六个算法课堂自学笔记](docs/六个算法课堂讲解.md) 是一份自学笔记：从题目需要什么结果开始，用小图手算，推导步骤，再回网页用大图检验。每节都有教材印刷页、PDF 页和对应代码。

## Windows 启动

在项目根目录打开 PowerShell，用 Python 3.10 或更高版本运行以下命令。网页服务只需要 Python 标准库。

```powershell
python -B app.py
```

用 Edge 或 Chrome 打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。路网、页面和算法均在本机，课堂演示可以离线进行。按 Ctrl+C 停止服务。

若 8765 端口已被占用，可以用 `python -B app.py --port 8766` 并打开对应的本地地址。

## 交通场景：城市包、封路和回放

1. 在侧栏选择天津或北京，点「一键演示」播放该城的示例。也可以选择地标和策略，再点「开始搜索」。地标标记对应附近的机动车道路接入点。
2. 观察地图逐步标出已定型的路网节点和它们的前驱边。节点包含路口和道路形状采样点；这些标记不等于最终行车路线。在播放中暂停、继续、调速或跳到结果。播放结束后查看最终路线、经过道路和本次定型的节点数。
3. 在「修改道路」中点选地图上的路段，或从下拉框选择路段并封闭。天津示例可指定**马场道 · 路段 253**，在最短距离策略下重新搜索，里程从约 **1,144 m 增至 1,551 m**。搜索后编辑区会收起，再点「修改道路 → 恢复此段」，重新搜索可回到 1,144 m。
4. 「随机封路」每次从该城尚开放的路段中随机抽取 1～3 段，当前路线也可能仍然畅通。每段按原始道路记录的可通行方向一起封闭和恢复。同一页面会话内可以切换城市、起终点或策略，各城分别保留封路状态；刷新页面可重新开始。
5. 点击「导入城市包」，从 `examples/` 选择一份 JSON 即可查询。可以连续导入多个城市，再从侧栏切换。导入会在项目 `local_data/cities/` 内保存副本，重启后仍可用。「移除城市」删除导入副本，原示例文件可再次使用。 [样区与导入包清单](data/README.md)

天津「五大道公园 → 天津音乐厅」在全部道路开放时有以下结果。切换策略后点「开始搜索」，可以对照三项代价。

| 当前策略 | 路线距离 | 预计通行时间 | 路面加权代价 |
| --- | ---: | ---: | ---: |
| 最短距离 | 1.14 km | 164 秒 | 1,357 加权米 |
| 预计最快 | 1.22 km | 157 秒 | 1,390 加权米 |
| 优先路面条件 | 1.16 km | 163 秒 | 1,287 加权米 |

## 图模型和算法

每个 OpenStreetMap 道路节点是图的顶点，每条连续道路线段按通行方向生成一条或两条有向边。两条道路通过共享节点连通。坐标用于计算道路线段长度与绘制位置。课堂模型的范围为固定城区样本和机动车道路单行关系，转向限制、临时管制和实时路况属于模型边界。

Dijkstra 通过最小堆取出当前累计代价最小的顶点，再尝试用开放的出边缩短相邻顶点的代价。每次搜索只运行一次 Dijkstra，取本次的权重和封路条件。动画显示每次有效出堆的节点及其前驱，跳过过期堆项。节点计数包含起点和定型的终点。

到达终点后按前驱及实际通行的边回溯路线，平行边的路名和指标对应所选的那一条。起终点相同时返回零代价，封路导致不可达时仍可查看实际搜索过程。

三种策略各自将一种边权求和并最小化。界面汇总同一条路线的三项指标，便于比较。

| 策略 | 每条有向边的权重 | 结果单位 |
| --- | --- | --- |
| 最短距离 | 相邻道路节点的球面距离 | m 或 km |
| 预计最快 | 长度（m）× 3.6 ÷ 参考车速（km/h）× 模拟拥堵倍率 | 秒或分钟 |
| 优先路面条件 | 长度（m）× 路面惩罚倍率 | 加权 m 或加权 km |

## 城市包格式

参照 [济南示例](examples/jinan.json) 准备 UTF-8 JSON 文件。单个文件上限为 12 MiB。城市标识在当前列表中唯一，由小写字母开头，最多 64 个小写字母、数字、短横线或下划线。

| 字段 | 用途 |
| --- | --- |
| `city_id`、`city_name`、`area_name` | 城市标识、显示名、样区名 |
| `source_url`、`extracted_on`、`license` | 数据来源链接、提取日期和许可 |
| `attribution`、`license_url` | 可选的数据署名与许可链接。随附 JSON 包均包含这两项 |
| `bounds` | 依次为西界经度、南界纬度、东界经度、北界纬度 |
| `nodes` | 每项为 `[节点整数编号, 经度, 纬度]`，节点编号唯一 |
| `roads` | 每项含整数 `id`、`name` 和 `surface`（可为 null）、表中的 `highway` 类别、`oneway`（0、1、-1）以及按原始方向排列的 `nodes` 编号列表 |
| `landmarks` | 每个地标含唯一文本 `id`、显示 `name` 和道路上的整数接入节点 `node` |
| `demo` | `start`、`end` 引用地标标识，`strategy` 为 `distance`、`time` 或 `surface` |

页面中的路段编号按当前包的道路记录顺序从 0 起排，用于区分同名道路和同一 OSM 道路裁剪后的多个片段。

## 测试

在已安装 pytest 和 NetworkX 的同一 Python 环境中运行：

```powershell
python -B -m pytest -q -p no:cacheprovider
```

交通测试覆盖手算小图、真实路网的 NetworkX 对照、每次搜索只运行一次、封路恢复、平行边、单行方向、同起终点、不可达，以及城市包导入、持久保存和移除。

五个教学算法使用 Node.js 的内置测试器（Node 20+，无需 npm install）：

```powershell
node --test tests/algorithms.test.mjs
```

两套命令仅供开发验收；课堂展示无需安装 Node、pytest 或 NetworkX。
