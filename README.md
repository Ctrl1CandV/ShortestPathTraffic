# 天津城区最短路径

图论课程设计「最短路径问题在城市交通规划中的应用」。在天津五大道—小白楼的真实二维机动车路网上，比较最短距离、预计最快与优先路面条件三种路线。

## Windows 启动

在项目根目录打开 PowerShell，用已安装的 Python 运行以下命令。

```powershell
python -B app.py
```

用 Edge 或 Chrome 打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。路网、页面和算法均在本机，课堂演示可以离线进行。按 Ctrl+C 停止服务。

若 8765 端口已被占用，可以用 `python -B app.py --port 8766` 并打开对应的本地地址。

## 课堂演示

点击「一键演示」载入「五大道公园 → 天津音乐厅」，再依次切换三种策略。图上标出当前路线和起终点，侧栏列出经过道路和三项指标。也可自选地标，地图标记对应地标附近的机动车道路接入点。

随附快照里，三种策略分别选择了不同的路线。先看最短距离，再切到预计最快，对照里程和估算时长。优先路面条件时，路面加权代价降为 1,287 加权米。

| 当前策略 | 路线距离 | 预计通行时间 | 路面加权代价 |
| --- | ---: | ---: | ---: |
| 最短距离 | 1.14 km | 164 秒 | 1,357 加权米 |
| 预计最快 | 1.22 km | 157 秒 | 1,390 加权米 |
| 优先路面条件 | 1.16 km | 163 秒 | 1,287 加权米 |

## 图模型和算法

每个 OpenStreetMap 道路节点是图的顶点，每条连续道路线段按通行方向生成一条或两条有向边。两条道路通过共享节点连通。坐标用于计算道路线段长度与绘制位置。课堂模型的范围为固定城区样本和机动车道路单行关系，转向限制、临时管制和实时路况属于模型边界。

Dijkstra 通过最小堆取出当前代价最小的顶点，再尝试用各出边缩短其相邻顶点的代价。从堆中取出当前有效的终点时，非负边权保证终点代价已最优。通过记录前一顶点和实际经过的边回溯路线，平行边的距离、路名和其他指标也能正确对应。查询起点等于终点时返回零代价，终点不可达时返回无路线。

三种策略各自将一种边权求和并最小化。界面汇总同一条路线的三项指标，便于比较。

| 策略 | 每条有向边的权重 | 结果单位 |
| --- | --- | --- |
| 最短距离 | 相邻道路节点的球面距离 | m 或 km |
| 预计最快 | 长度（m）× 3.6 ÷ 参考车速（km/h）× 模拟拥堵倍率 | 秒或分钟 |
| 优先路面条件 | 长度（m）× 路面惩罚倍率 | 加权 m 或加权 km |

参考车速、拥堵倍率和路面缺省倍率都是固定课堂参数。材质未知或超出下表映射时，按道路类别取路面缺省倍率。路面加权代价可以理解为按路况折算后的距离，越小越受此策略偏好。

| motorway_link | 40 | 1.35 | 1.05 |

| primary | 50 | 2.00 | 1.04 |
| primary_link | 35 | 1.35 | 1.08 |

| secondary_link | 30 | 1.25 | 1.12 |
| tertiary | 35 | 1.25 | 1.14 |
| tertiary_link | 25 | 1.20 | 1.18 |
| residential | 25 | 1.10 | 1.28 |

## 测试

在已安装 pytest 和 NetworkX 的同一 Python 环境中运行：

```powershell
python -B -m pytest -q -p no:cacheprovider
```

测试覆盖手算小图、真实路网的 NetworkX 对照、单行方向、平行边、同起终点、不可达和并列最优。运行网页只需要 Python 标准库。
